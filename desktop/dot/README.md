# หุ่น Dot สำหรับ Windows

หุ่น Dot เปิดหน้าต่างพร้อมเสียงภาษาไทยเมื่อยอดซื้อเข้าเกณฑ์แจ้งเตือน และอ่านสรุปงานเช้าของร้านจำลอง niicez54 ทุกวันเวลา 08:00 น. ตามเวลาไทย ใช้ได้ขณะปิดเว็บร้าน เครื่องต้องเปิดอยู่ เข้าสู่ระบบ Windows และต่ออินเทอร์เน็ตเพื่ออ่านข้อมูลล่าสุด

## เริ่มใช้งาน

1. แตกไฟล์ ZIP ทั้งหมดไว้ในโฟลเดอร์เดียวกัน แล้วดับเบิลคลิก `Install.cmd`
2. เปิดเมนู Start → **Raan Rao Dot → Preview Dot** เพื่อลองดูหุ่นและฟังเสียง ตรวจระดับเสียงของ Windows และลำโพงที่เลือก
3. หลังติดตั้ง Dot จะเริ่มทำงานทันทีและเปิดอัตโนมัติทุกครั้งที่ลงชื่อเข้าใช้ Windows บัญชีนี้

หากมีเสียงอ่านภาษาไทยที่รองรับ Dot จะอ่านตัวเลขในข้อความ หากไม่มีเสียงที่รองรับ หุ่นจะเล่นเสียงภาษาไทยที่แนบมาและแสดงตัวเลขบนหน้าต่าง

**พักหรือถอน** เลือก **Stop Dot** ในเมนู Start เพื่อหยุดจนกว่าจะเปิด **Start Dot** หรือลงชื่อเข้าใช้รอบใหม่ เลือก **Uninstall Dot** เพื่อถอนตัวหุ่นและปิดการเริ่มอัตโนมัติ หรือใช้ `Stop.cmd` และ `Uninstall.cmd` ในโฟลเดอร์ที่แตกไฟล์

## ข้อมูลและการติดตั้ง

Dot อ่านข้อมูลสรุปจาก `https://raan-rao-regional-hackathon.niicez54.chatgpt.site/api/dot-summary` และเก็บสถานะการเตือนใน `%LOCALAPPDATA%\RaanRao\Dot` เพื่อจำเหตุที่เคยแจ้งแล้ว โปรแกรมอยู่ในโฟลเดอร์ย่อย `app` การถอนการติดตั้งจะเก็บประวัติการเตือนในเครื่องไว้

ตัวเรียกใช้ Windows PowerShell 5.1 ตั้ง `RemoteSigned` เฉพาะโปรเซสที่เรียกโปรแกรม นโยบายองค์กรยังมีผล ใช้สิทธิ์ของผู้ใช้ปัจจุบัน หาก Windows แจ้งว่าบล็อกไฟล์ที่ดาวน์โหลด ให้ตรวจที่มาจากหน้า Dot ของร้านและตรวจนโยบายของเครื่องก่อนติดตั้ง
